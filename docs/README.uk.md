# AgentBar

Легкий застосунок для рядка меню macOS: показує, скільки лімітів **Claude**, **Codex** і **Cursor** ви вже використали, а також статистику токенів і скільки те саме використання коштувало б через публічні API.

## Можливості

- **Ліміти з першого погляду** — 5-годинні й тижневі вікна Claude і Codex, включені пули Cursor; у кожного смужка прогресу, час до скидання та точна дата.
- **Тижневі ліміти за моделями** Claude (Opus, Sonnet, Fable, …), щойно API їх повертає.
- **Статистика використання** — токени за типами, вартість, розбивка за моделями та проєктами, графік за днями; Сьогодні / 7 днів / 30 днів / Увесь час.
- **Сповіщення**, коли ліміт перевищує поріг: загальний поріг і правила для кожного ліміту (вимкнути, власний поріг).
- **Автооновлення даних** за бажанням, запуск при вході, 17 мов інтерфейсу.
- **Оновлення «по повітрю»** з GitHub Releases із перевіркою SHA-256.
- **Без акаунтів і телеметрії.** AgentBar читає токени, які офіційні клієнти вже зберігають на вашому Mac, і звертається лише до API самих провайдерів.

## Вимоги

- macOS 14 Sonoma або новіша (Apple silicon чи Intel).
- Принаймні один із клієнтів із виконаним входом: [Claude Code](https://claude.com/claude-code), [Codex](https://openai.com/codex) (CLI або застосунок), [Cursor](https://cursor.com). Невикористовуваних провайдерів можна сховати в налаштуваннях.

## Встановлення

1. Завантажте `AgentBar.zip` з [останнього релізу](https://github.com/funbool/agentbar/releases/latest).
2. Розпакуйте й перемістіть `AgentBar.app` до `/Applications`.
3. Відкрийте застосунок. Він сам додасться до об'єктів входу (це можна вимкнути в налаштуваннях).

**Gatekeeper.** Релізи підписані ad hoc і не нотаризовані. Якщо macOS відмовляється відкрити щойно завантажену копію, один раз відкрийте її через правий клік → *Відкрити* або зніміть прапорець карантину:

```bash
xattr -dr com.apple.quarantine /Applications/AgentBar.app
```

**Запит Keychain.** Під час першого оновлення Claude macOS запитає, чи може `security` читати елемент *Claude Code-credentials*. Виберіть **Always Allow** (Завжди дозволяти). Запит може з'явитися знову після ротації токена Claude Code — це нормально.

Також можна [зібрати з початкового коду](#збирання-з-початкового-коду).

## Як це працює

AgentBar ніколи не просить увійти в акаунт. Він читає облікові дані, які кожен клієнт уже зберігає на вашому Mac, і викликає ті самі ендпоінти, що й самі клієнти.

| Провайдер | Звідки беруться облікові дані | Ендпоінт | Що показується |
|---|---|---|---|
| Claude | Елемент Keychain `Claude Code-credentials` (через `/usr/bin/security`) | `api.anthropic.com/api/oauth/usage` | 5-годинне вікно, тижневе вікно, тижневі ліміти за моделями |
| Codex | `~/.codex/auth.json` (або `$CODEX_HOME/auth.json`) | `chatgpt.com/backend-api/wham/usage` | 5-годинне вікно, тижневе вікно, тариф |
| Cursor | `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` (лише читання) | `cursor.com/api/usage-summary`, `…/get-sand-usage-status` | Пул моделей Cursor (Auto / Composer / Grok), пул API-моделей, витрати понад план, тижневий Grok Bot, витрачено за цикл |

AgentBar не оновлює токени сам. Якщо провайдер показує *сесія закінчилася*, один раз відкрийте його клієнт — він оновить токен, і AgentBar підхопить його під час наступного оновлення.

## Панель

- Клік по іконці в рядку меню: усі провайдери оновлюються одразу; поки триває завантаження, показуються попередні значення.
- Смужки зелені до 60 %, жовті вище, червоні при досягненні порогу сповіщення.
- У кожного ліміту видно час, що лишився, і точний момент скидання, наприклад *скидання через 2год 15хв · чт, 24 вер. 20:00*.
- Дзвіночок поруч із лімітом відкриває його правило сповіщень (увімк./вимк., поріг).
- Унизу: статистика · оновити · налаштування · вийти.

## Статистика використання

Кнопка з графіком унизу панелі відкриває вікно статистики. Угорі перемикаються провайдер і період; наведення на графік показує підсумки дня або частку конкретної моделі.

| Провайдер | Джерело | Вартість |
|---|---|---|
| Claude | Транскрипти Claude Code (`~/.claude/projects/**/*.jsonl`), індексуються один раз і кешуються за файлами | Скільки те саме використання коштувало б через API: ввід/вивід за прайсом, запис кешу ×1.25 (TTL 5 хв) / ×2 (TTL 1 год), читання кешу ×0.1 |
| Codex | Логи сесій (`~/.codex/sessions/**/*.jsonl`) | Прайс OpenAI API; кешований ввід ×0.1. Для моделей без публічної ціни показуються лише токени |
| Cursor | Події використання з дашборда Cursor, кешуються локально. Під час першого відкриття ви обираєте: завантажити всю історію чи лише поточний білінговий цикл; далі довантажуються лише нові події | Як повідомляє Cursor для кожного запиту |

**Чому підсумки Claude в AgentBar відрізняються від `/stats` у Claude Code.** Claude Code рахує кожен рядок транскрипту, а відповідь із кількох блоків (thinking, текст, виклики інструментів) записується кількома рядками з тим самим записом usage — такі відповіді враховуються кілька разів. AgentBar рахує кожну відповідь один раз за фінальними значеннями — саме стільки білить API — і показує поруч цифру Claude Code для звірки.

Індексація 700 МБ транскриптів триває близько 10 секунд уперше й менше секунди потім. Кеші лежать у `~/Library/Application Support/AgentBar/`.

## Сповіщення

- Увімкніть сповіщення в Налаштування → Сповіщення та виберіть поріг за замовчуванням (50–95 %).
- Будь-який ліміт можна вимкнути або задати йому власний поріг — з налаштувань або через дзвіночок у панелі.
- Надходить одне сповіщення на ліміт за цикл скидання.
- Ліміти перевіряються під час кожного оновлення: за розкладом, якщо ввімкнено автооновлення, інакше — лише при відкритті панелі.

## Налаштування

- **Основні** — інтервал автооновлення (вимк. / 1 / 5 / 15 / 30 / 60 хв), видимі провайдери, мова, запуск при вході, оновлення.
- **Сповіщення** — загальний перемикач, поріг за замовчуванням, правила для лімітів.

## Оновлення

AgentBar перевіряє GitHub Releases раз на добу та за кнопкою *Перевірити оновлення*. Коли є новіша версія, у панелі з'являється кнопка *Оновити*. Оновлення завантажується, його SHA-256 звіряється з опублікованою контрольною сумою, перевіряються ідентифікатор бандла та версія, старий застосунок переміщується до Смітника, новий запускається. Будь-який реліз можна встановити й вручну зі [сторінки релізів](https://github.com/funbool/agentbar/releases).

## Збирання з початкового коду

Потрібен Xcode 15 або новіший (Swift 5.9). Сторонніх залежностей немає.

```bash
git clone https://github.com/funbool/agentbar.git
cd agentbar
swift test                 # юніт-тести
./scripts/build.sh         # -> build/AgentBar.app
./scripts/install.sh       # зібрати, скопіювати в /Applications і запустити
```

Режими налагодження (запускайте бінарник із бандла або `.build/debug/AgentBar`):

```bash
AgentBar --dump            # один раз опитати всіх провайдерів і вивести розібрані ліміти
AgentBar --raw             # вивести сирий JSON кожного ендпоінта
AgentBar --stats           # проіндексувати локальні логи Claude/Codex і вивести підсумки
AgentBar --cursor-events   # завантажити події Cursor і вивести підсумки
AgentBar --update          # виконати повний цикл оновлення без UI
```

### Випуск релізу

```bash
./scripts/release.sh 0.2.0
```

Скрипт піднімає версію в `Packaging/Info.plist`, ставить тег `v0.2.0` і пушить. GitHub Actions запускає тести, збирає застосунок, публікує `AgentBar.zip` і `AgentBar.zip.sha256` як реліз, а запущені копії підхоплюють його під час наступної перевірки.

## Приватність і безпека

- **Читає:** елемент Keychain Claude Code, `~/.codex/auth.json`, `state.vscdb` Cursor (лише читання), локальні транскрипти та логи сесій.
- **Пише:** налаштування й кеші в `~/Library/Application Support/AgentBar/`.
- **Мережа:** `api.anthropic.com`, `chatgpt.com`, `cursor.com` (ваші ж дані про використання) та `api.github.com` / `github.com` (перевірка й завантаження оновлень). Більше нічого.
- Релізи збирає GitHub Actions із позначеного тегом коду; workflow лежить у `.github/workflows/release.yml`.

## Усунення проблем

| Симптом | Що робити |
|---|---|
| *Немає входу — відкрийте …* | Увійдіть у цей клієнт один раз; AgentBar прочитає збережений токен під час наступного оновлення. |
| Запит Keychain з'являється знову | Виберіть *Always Allow*. Новий запит через деякий час означає, що Claude Code змінив токен. |
| Cursor нічого не показує | Відкрийте Cursor один раз, щоб він оновив сесійний токен, потім оновіть AgentBar. |
| Застосунок не відкривається після завантаження | Gatekeeper — див. [Встановлення](#встановлення). |
| Статистика «зависла» на *Індексація…* | Перша індексація великих тек із транскриптами триває певний час; далі працює кеш. |
