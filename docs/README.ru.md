# AgentBar

Лёгкое приложение для строки меню macOS: показывает, сколько лимитов **Claude**, **Codex** и **Cursor** вы уже израсходовали, а также статистику токенов и сколько то же использование стоило бы через публичные API.

[![Release](https://img.shields.io/github/v/release/funbool/agentbar?display_name=tag)](https://github.com/funbool/agentbar/releases/latest)

## Возможности

- **Лимиты с первого взгляда** — 5-часовые и недельные окна Claude и Codex, включённые пулы Cursor; у каждого прогресс-бар, оставшееся время и точная дата сброса.
- **Недельные лимиты по моделям** Claude (Opus, Sonnet, Fable, …), как только API их отдаёт.
- **Статистика использования** — токены по типам, стоимость, разбивка по моделям и проектам, график по дням; Сегодня / 7 дней / 30 дней / Всё время.
- **Уведомления** при достижении порога: общий порог по умолчанию и правила для каждого лимита (отключить, свой порог).
- **Автообновление данных** по желанию, запуск при входе, 17 языков интерфейса.
- **Обновления по воздуху** из GitHub Releases с проверкой SHA-256.
- **Без аккаунтов и телеметрии.** AgentBar читает токены, которые официальные клиенты уже хранят на вашем Mac, и обращается только к API самих провайдеров.

## Требования

- macOS 14 Sonoma или новее (Apple silicon или Intel).
- Хотя бы один из клиентов с выполненным входом: [Claude Code](https://claude.com/claude-code), [Codex](https://openai.com/codex) (CLI или приложение), [Cursor](https://cursor.com). Неиспользуемых провайдеров можно скрыть в настройках.

## Установка

1. Скачайте `AgentBar.zip` из [последнего релиза](https://github.com/funbool/agentbar/releases/latest).
2. Распакуйте и перенесите `AgentBar.app` в `/Applications`.
3. Откройте приложение. Оно само добавится в объекты входа (это можно отключить в настройках).

**Gatekeeper.** Релизы подписаны ad hoc и не нотаризованы. Если macOS отказывается открыть только что скачанную копию, один раз откройте её через правый клик → *Открыть* или снимите флаг карантина:

```bash
xattr -dr com.apple.quarantine /Applications/AgentBar.app
```

**Запрос Keychain.** При первом обновлении Claude macOS спросит, можно ли `security` читать элемент *Claude Code-credentials*. Выберите **Always Allow** (Всегда разрешать). Запрос может появиться снова после ротации токена Claude Code — это нормально.

Также можно [собрать из исходников](#сборка-из-исходников).

## Как это работает

AgentBar никогда не просит войти в аккаунт. Он читает учётные данные, которые каждый клиент уже хранит на вашем Mac, и вызывает те же эндпоинты, что и сами клиенты.

| Провайдер | Откуда берутся учётные данные | Эндпоинт | Что показывается |
|---|---|---|---|
| Claude | Элемент Keychain `Claude Code-credentials` (через `/usr/bin/security`) | `api.anthropic.com/api/oauth/usage` | 5-часовое окно, недельное окно, недельные лимиты по моделям |
| Codex | `~/.codex/auth.json` (или `$CODEX_HOME/auth.json`) | `chatgpt.com/backend-api/wham/usage` | 5-часовое окно, недельное окно, тариф |
| Cursor | `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` (только чтение) | `cursor.com/api/usage-summary`, `…/get-sand-usage-status` | Пул моделей Cursor (Auto / Composer / Grok), пул API-моделей, расходы сверх плана, недельный Grok Bot, потрачено за цикл |

AgentBar не обновляет токены сам. Если провайдер показывает *сессия истекла*, один раз откройте его клиент — он обновит токен, и AgentBar подхватит его при следующем обновлении.

## Панель

- Клик по иконке в строке меню: все провайдеры обновляются сразу; пока идёт загрузка, показываются прошлые значения.
- Бары зелёные до 60 %, жёлтые выше, красные при достижении порога уведомления.
- У каждого лимита видно оставшееся время и точный момент сброса, например *сброс через 2ч 15м · чт, 24 сент. 20:00*.
- Колокольчик рядом с лимитом открывает его правило уведомлений (вкл/выкл, порог).
- Внизу: статистика · обновить · настройки · выйти.

## Статистика использования

Кнопка с графиком внизу панели открывает окно статистики. Сверху переключаются провайдер и период; наведение на график показывает итоги дня или долю конкретной модели.

| Провайдер | Источник | Стоимость |
|---|---|---|
| Claude | Транскрипты Claude Code (`~/.claude/projects/**/*.jsonl`), индексируются один раз и кэшируются по файлам | Сколько то же использование стоило бы через API: ввод/вывод по прайсу, запись кэша ×1.25 (TTL 5 мин) / ×2 (TTL 1 ч), чтение кэша ×0.1 |
| Codex | Логи сессий (`~/.codex/sessions/**/*.jsonl`) | Прайс OpenAI API; кэшированный ввод ×0.1. Для моделей без публичной цены показываются только токены |
| Cursor | События использования из дашборда Cursor, кэшируются локально. При первом открытии вы выбираете: загрузить всю историю или только текущий биллинг-цикл; дальше догружаются только новые события | Как сообщает Cursor по каждому запросу |

**Почему итоги Claude в AgentBar отличаются от `/stats` в Claude Code.** Claude Code считает каждую строку транскрипта, а ответ из нескольких блоков (thinking, текст, вызовы инструментов) записывается несколькими строками с одной и той же записью usage — такие ответы учитываются несколько раз. AgentBar считает каждый ответ один раз по финальным значениям usage — именно столько биллит API — и показывает рядом цифру Claude Code для сверки.

Индексация 700 МБ транскриптов занимает около 10 секунд в первый раз и меньше секунды потом. Кэши лежат в `~/Library/Application Support/AgentBar/`.

## Уведомления

- Включите уведомления в Настройки → Уведомления и выберите порог по умолчанию (50–95 %).
- Любой лимит можно отключить или задать ему свой порог — из настроек или по колокольчику в панели.
- Приходит одно уведомление на лимит за цикл сброса.
- Лимиты проверяются при каждом обновлении: по расписанию, если включено автообновление, иначе — только при открытии панели.

## Настройки

- **Основные** — интервал автообновления (выкл / 1 / 5 / 15 / 30 / 60 мин), видимые провайдеры, язык, запуск при входе, обновления.
- **Уведомления** — общий переключатель, порог по умолчанию, правила по лимитам.

## Обновления

AgentBar проверяет GitHub Releases раз в сутки и по кнопке *Проверить обновления*. Когда есть новая версия, в панели появляется кнопка *Обновить*. Обновление скачивается, его SHA-256 сверяется с опубликованной контрольной суммой, проверяются идентификатор бандла и версия, старое приложение отправляется в Корзину, новое запускается. Любой релиз можно поставить и вручную со [страницы релизов](https://github.com/funbool/agentbar/releases).

## Сборка из исходников

Нужен Xcode 15 или новее (Swift 5.9). Сторонних зависимостей нет.

```bash
git clone https://github.com/funbool/agentbar.git
cd agentbar
swift test                 # юнит-тесты
./scripts/build.sh         # -> build/AgentBar.app
./scripts/install.sh       # собрать, скопировать в /Applications и запустить
```

Отладочные режимы (запускайте бинарник из бандла или `.build/debug/AgentBar`):

```bash
AgentBar --dump            # один раз опросить всех провайдеров и вывести разобранные лимиты
AgentBar --raw             # вывести сырой JSON каждого эндпоинта
AgentBar --stats           # проиндексировать локальные логи Claude/Codex и вывести итоги
AgentBar --cursor-events   # загрузить события Cursor и вывести итоги
AgentBar --update          # прогнать полный цикл обновления без UI
```

### Выпуск релиза

```bash
./scripts/release.sh 0.2.0
```

Скрипт поднимает версию в `Packaging/Info.plist`, ставит тег `v0.2.0` и пушит. GitHub Actions запускает тесты, собирает приложение, публикует `AgentBar.zip` и `AgentBar.zip.sha256` как релиз, а запущенные копии подхватывают его при следующей проверке.

## Приватность и безопасность

- **Читает:** элемент Keychain Claude Code, `~/.codex/auth.json`, `state.vscdb` Cursor (только чтение), локальные транскрипты и логи сессий.
- **Пишет:** настройки и кэши в `~/Library/Application Support/AgentBar/`.
- **Сеть:** `api.anthropic.com`, `chatgpt.com`, `cursor.com` (ваши же данные об использовании) и `api.github.com` / `github.com` (проверка и загрузка обновлений). Больше ничего.
- Релизы собирает GitHub Actions из помеченного тегом исходника; workflow лежит в `.github/workflows/release.yml`.

## Решение проблем

| Симптом | Что делать |
|---|---|
| *Нет входа — откройте …* | Войдите в этот клиент один раз; AgentBar прочитает сохранённый токен при следующем обновлении. |
| Запрос Keychain появляется снова | Выберите *Always Allow*. Новый запрос спустя время означает, что Claude Code сменил токен. |
| Cursor ничего не показывает | Откройте Cursor один раз, чтобы он обновил сессионный токен, затем обновите AgentBar. |
| Приложение не открывается после скачивания | Gatekeeper — см. [Установка](#установка). |
| Статистика «зависла» на *Индексация…* | Первая индексация больших папок с транскриптами занимает время; дальше работает кэш. |
