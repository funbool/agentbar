# AgentBar

**Claude**, **Codex** және **Cursor** лимиттерінің қаншасын пайдаланғаныңызды көрсететін жеңіл macOS мәзір жолағы қолданбасы — сонымен қатар токен статистикасы және дәл сол пайдалану ашық API арқылы қанша тұрар еді.

## Мүмкіндіктер

- **Лимиттер бір қарағанда** — Claude мен Codex үшін 5 сағаттық және апталық терезелер, Cursor үшін жоспарға кіретін пайдалану пулдары; әрқайсысында прогресс жолағы, қалпына келгенге дейінгі уақыт және нақты күн.
- **Модель бойынша апталық лимиттер** Claude үшін (Opus, Sonnet, Fable, …), API хабарлаған сәтте.
- **Пайдалану статистикасы** — түрі бойынша токендер, құны, модель мен жоба бойынша бөлу, күндік график; Бүгін / 7 күн / 30 күн / Барлық уақыт.
- **Хабарландырулар** лимит шектен асқанда: жалпы шек және әр лимит үшін ережелер (өшіру, жеке шек).
- **Қалау бойынша автожаңарту**, кіргенде іске қосу, 17 интерфейс тілі.
- **Ауа арқылы жаңарту** GitHub Releases-тен, SHA-256 арқылы тексеріледі.
- **Аккаунт та, телеметрия да жоқ.** AgentBar ресми клиенттердің Mac-та әлдеқашан сақтаған токендерін оқиды және тек провайдерлердің өз API-ларына жүгінеді.

## Талаптар

- macOS 14 Sonoma немесе одан жаңа (Apple Silicon немесе Intel).
- Кірілген кем дегенде бір клиент: [Claude Code](https://claude.com/claude-code), [Codex](https://openai.com/codex) (CLI немесе қолданба), [Cursor](https://cursor.com). Пайдаланылмайтын провайдерлерді Баптауларда жасыруға болады.

## Орнату

1. [Соңғы релизден](https://github.com/funbool/agentbar/releases/latest) `AgentBar.zip` жүктеп алыңыз.
2. Архивті ашып, `AgentBar.app` файлын `/Applications` қалтасына жылжытыңыз.
3. Қолданбаны ашыңыз. Ол өзін кіру элементі ретінде тіркейді (Баптауларда өшіруге болады).

**Gatekeeper.** Релиздер ad hoc қол қойылған, нотариалды емес. macOS жаңа жүктелген көшірмені ашудан бас тартса, оң жақ батырма → *Ашу* пәрменін бір рет таңдаңыз немесе карантин белгісін алып тастаңыз:

```bash
xattr -dr com.apple.quarantine /Applications/AgentBar.app
```

**Keychain сұрауы.** Алғашқы Claude жаңартуында macOS `security` құралының *Claude Code-credentials* элементін оқи алатынын сұрайды. **Always Allow** (Әрқашан рұқсат ету) таңдаңыз. Claude Code токенін ауыстырғаннан кейін сұрау қайта шығуы мүмкін — бұл қалыпты жағдай.

Сондай-ақ [бастапқы кодтан құрастыруға](#бастапқы-кодтан-құрастыру) болады.

## Қалай жұмыс істейді

AgentBar ешқашан кіруді сұрамайды. Ол әр клиенттің Mac-та сақтаған тіркелгі деректерін оқиды және клиенттер қолданатын эндпоинттерді шақырады.

| Провайдер | Тіркелгі деректері қайдан | Эндпоинт | Не көрсетіледі |
|---|---|---|---|
| Claude | Keychain элементі `Claude Code-credentials` (`/usr/bin/security` арқылы оқылады) | `api.anthropic.com/api/oauth/usage` | 5 сағаттық терезе, апталық терезе, модель бойынша апталық лимиттер |
| Codex | `~/.codex/auth.json` (немесе `$CODEX_HOME/auth.json`) | `chatgpt.com/backend-api/wham/usage` | 5 сағаттық терезе, апталық терезе, жоспар |
| Cursor | `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` (тек оқу) | `cursor.com/api/usage-summary`, `…/get-sand-usage-status` | Cursor модельдерінің пулы (Auto / Composer / Grok), API модельдерінің пулы, жоспардан тыс шығын, апталық Grok Bot, кезеңдегі шығын |

AgentBar токендерді жаңартпайды. Провайдер *сеанс мерзімі бітті* деп көрсетсе, сол клиентті бір рет ашыңыз — ол токенді жаңартады, AgentBar келесі жаңартуда алады.

## Панель

- Мәзір жолағындағы белгішені басыңыз: барлық провайдерлер бірден жаңарады; жүктелу кезінде алдыңғы мәндер көрсетіледі.
- Жолақтар 60 %-ға дейін жасыл, одан жоғары сары, хабарландыру шегіне жеткенде қызыл.
- Әр лимит қалған уақытты және нақты қалпына келу сәтін көрсетеді, мысалы *2сағ 15мин кейін қалпына келеді · бс, 24 қыр. 20:00*.
- Лимиттің жанындағы қоңырау оның хабарландыру ережесін ашады (қосу/өшіру, шек).
- Төменгі жол: статистика · жаңарту · баптаулар · шығу.

## Пайдалану статистикасы

Төменгі жолдағы график батырмасы статистика терезесін ашады. Жоғарыда провайдер мен кезеңді ауыстырасыз; графикке меңзерді апарғанда күн қорытындысын немесе нақты модельдің үлесін көресіз.

| Провайдер | Дереккөз | Құны |
|---|---|---|
| Claude | Claude Code транскрипттері (`~/.claude/projects/**/*.jsonl`), бір рет индекстеліп, файл бойынша кэштеледі | Дәл сол пайдалану API арқылы қанша тұрар еді: кіріс/шығыс прайс бойынша, кэшке жазу ×1,25 (5 мин TTL) / ×2 (1 сағ TTL), кэштен оқу ×0,1 |
| Codex | Сеанс журналдары (`~/.codex/sessions/**/*.jsonl`) | OpenAI API прайсы; кэштелген кіріс ×0,1. Ашық бағасы жоқ модельдер үшін тек токендер көрсетіледі |
| Cursor | Cursor тақтасындағы пайдалану оқиғалары, жергілікті кэштеледі. Алғаш ашқанда бүкіл тарихты немесе тек ағымдағы есеп айырысу кезеңін жүктеуді таңдайсыз; кейін тек жаңа оқиғалар жүктеледі | Cursor әр сұрау үшін хабарлайтын сома |

**AgentBar-дағы Claude қорытындысы неге Claude Code-тағы `/stats`-тан өзгеше.** Claude Code транскрипттің әр жолын санайды, ал бірнеше блоктан (ойлау, мәтін, құрал шақырулары) тұратын жауап бір usage жазбасын бөлісетін бірнеше жол ретінде жазылады — сондықтан бірнеше рет саналады. AgentBar әр жауапты соңғы мәндерімен бір рет санайды — API дәл соны есептейді — және салыстыру үшін Claude Code санын қасында көрсетеді.

700 МБ транскриптті индекстеу алғаш рет шамамен 10 секунд, кейін бір секундтан әлдеқайда аз уақыт алады. Кэштер `~/Library/Application Support/AgentBar/` ішінде.

## Хабарландырулар

- Баптаулар → Хабарландырулар бөлімінде хабарландыруларды қосып, әдепкі шекті таңдаңыз (50–95 %).
- Кез келген лимитті өшіруге немесе оған жеке шек қоюға болады — Баптаулардан немесе панельдегі қоңырау арқылы.
- Әр лимит үшін қалпына келу кезеңіне бір хабарландыру келеді.
- Лимиттер әр жаңартуда тексеріледі: автожаңарту қосулы болса кесте бойынша, әйтпесе тек панель ашылғанда.

## Баптаулар

- **Негізгі** — жаңарту аралығы (өшірулі / 1 / 5 / 15 / 30 / 60 мин), көрінетін провайдерлер, тіл, кіргенде іске қосу, жаңартулар.
- **Хабарландырулар** — жалпы ауыстырғыш, әдепкі шек, лимиттер бойынша ережелер.

## Жаңартулар

AgentBar GitHub Releases-ті күніне бір рет және *Жаңартуларды тексеру* батырмасын басқанда тексереді. Жаңа нұсқа болса, панельде *Жаңарту* батырмасы шығады. Жаңарту жүктеледі, SHA-256 жарияланған бақылау сомасымен салыстырылады, бандл идентификаторы мен нұсқасы тексеріледі, ескі қолданба Себетке жіберіледі, жаңасы іске қосылады. Кез келген релизді [релиздер бетінен](https://github.com/funbool/agentbar/releases) қолмен де орнатуға болады.

## Бастапқы кодтан құрастыру

Xcode 15 немесе одан жаңа қажет (Swift 5.9). Үшінші тарап тәуелділіктері жоқ.

```bash
git clone https://github.com/funbool/agentbar.git
cd agentbar
swift test                 # бірлік тесттер
./scripts/build.sh         # -> build/AgentBar.app
./scripts/install.sh       # құрастыру, /Applications-ке көшіру және іске қосу
```

Отладка режимдері (бандлдағы бинарлықты немесе `.build/debug/AgentBar` іске қосыңыз):

```bash
AgentBar --dump            # әр провайдерді бір рет сұрап, талданған лимиттерді шығару
AgentBar --raw             # әр эндпоинттің шикі JSON-ын шығару
AgentBar --stats           # жергілікті Claude/Codex журналдарын индекстеп, қорытындыны шығару
AgentBar --cursor-events   # Cursor оқиғаларын жүктеп, қорытындыны шығару
AgentBar --update          # толық жаңарту циклін интерфейссіз орындау
```

### Релиз шығару

```bash
./scripts/release.sh 0.2.0
```

Скрипт `Packaging/Info.plist` ішіндегі нұсқаны көтереді, `v0.2.0` тегін қойып, push жасайды. GitHub Actions тесттерді іске қосады, қолданбаны құрастырады, `AgentBar.zip` және `AgentBar.zip.sha256` файлдарын релиз ретінде жариялайды, ал жұмыс істеп тұрған көшірмелер оны келесі тексеруде алады.

## Құпиялылық және қауіпсіздік

- **Оқиды:** Claude Code Keychain элементін, `~/.codex/auth.json`, Cursor `state.vscdb` (тек оқу), жергілікті транскрипттер мен сеанс журналдарын.
- **Жазады:** баптаулар мен кэштерді `~/Library/Application Support/AgentBar/` ішіне.
- **Желі:** `api.anthropic.com`, `chatgpt.com`, `cursor.com` (өзіңіздің пайдалану деректеріңіз) және `api.github.com` / `github.com` (жаңартуларды тексеру және жүктеу). Басқа ештеңе.
- Релиздерді GitHub Actions тегі бар бастапқы кодтан құрастырады; workflow `.github/workflows/release.yml` ішінде.

## Ақаулықтарды жою

| Белгі | Не істеу керек |
|---|---|
| *Кірілмеген — … ашыңыз* | Сол клиентке бір рет кіріңіз; AgentBar сақталған токенді келесі жаңартуда оқиды. |
| Keychain сұрауы қайта-қайта шығады | *Always Allow* таңдаңыз. Біраз уақыттан кейінгі жаңа сұрау Claude Code токенін ауыстырғанын білдіреді. |
| Cursor ештеңе көрсетпейді | Сеанс токенін жаңарту үшін Cursor-ды бір рет ашыңыз, содан кейін AgentBar-ды жаңартыңыз. |
| Жүктегеннен кейін қолданба ашылмайды | Gatekeeper — [Орнату](#орнату) бөлімін қараңыз. |
| Статистика *Индекстеу…* күйінде тұрып қалды | Үлкен транскрипт қалталарын алғаш индекстеу уақыт алады; кейінгі іске қосулар кэшті пайдаланады. |
