# AgentBar

macOS मेनू बार के लिए एक हल्का ऐप जो दिखाता है कि आपने **Claude**, **Codex** और **Cursor** की सीमाओं का कितना उपयोग किया है — साथ ही टोकन आँकड़े और यह कि वही उपयोग सार्वजनिक API के माध्यम से कितना खर्च होता।

## विशेषताएँ

- **एक नज़र में सीमाएँ** — Claude और Codex के लिए 5-घंटे और साप्ताहिक विंडो, Cursor के लिए प्लान में शामिल उपयोग पूल; हर एक के साथ प्रगति बार, रीसेट तक बचा समय और सटीक रीसेट तारीख।
- **मॉडल-वार साप्ताहिक सीमाएँ** Claude के लिए (Opus, Sonnet, Fable, …), जैसे ही API उन्हें रिपोर्ट करे।
- **उपयोग आँकड़े** — प्रकार के अनुसार टोकन, लागत, मॉडल और प्रोजेक्ट के अनुसार विभाजन, दैनिक चार्ट; आज / 7 दिन / 30 दिन / कुल।
- **सूचनाएँ** जब कोई सीमा किसी स्तर को पार करे, वैश्विक डिफ़ॉल्ट और प्रति-सीमा नियमों के साथ (म्यूट, अपना स्तर)।
- **वैकल्पिक स्वतः रीफ़्रेश**, लॉगिन पर लॉन्च, इंटरफ़ेस की 17 भाषाएँ।
- **ओवर-द-एयर अपडेट** GitHub Releases से, SHA-256 से सत्यापित।
- **कोई खाता नहीं, कोई टेलीमेट्री नहीं।** AgentBar वही टोकन पढ़ता है जो आधिकारिक क्लाइंट आपके Mac पर पहले से रखते हैं, और केवल प्रदाताओं के अपने API से बात करता है।

## आवश्यकताएँ

- macOS 14 Sonoma या नया (Apple Silicon या Intel)।
- इनमें से कम से कम एक क्लाइंट में साइन इन: [Claude Code](https://claude.com/claude-code), [Codex](https://openai.com/codex) (CLI या ऐप), [Cursor](https://cursor.com)। जिन प्रदाताओं का उपयोग नहीं करते उन्हें सेटिंग्स में छिपाया जा सकता है।

## इंस्टॉलेशन

1. [नवीनतम रिलीज़](https://github.com/funbool/agentbar/releases/latest) से `AgentBar.zip` डाउनलोड करें।
2. उसे अनज़िप करें और `AgentBar.app` को `/Applications` में ले जाएँ।
3. ऐप खोलें। यह खुद को लॉगिन आइटम के रूप में पंजीकृत कर लेता है (सेटिंग्स में बंद किया जा सकता है)।

**Gatekeeper.** रिलीज़ ad hoc हस्ताक्षरित हैं, नोटराइज़्ड नहीं। यदि macOS ताज़ा डाउनलोड की गई कॉपी खोलने से मना करे, तो ऐप पर राइट-क्लिक करके एक बार *Open* चुनें, या क्वारंटीन फ़्लैग हटा दें:

```bash
xattr -dr com.apple.quarantine /Applications/AgentBar.app
```

**Keychain प्रॉम्प्ट।** पहले Claude रीफ़्रेश पर macOS पूछता है कि क्या `security` *Claude Code-credentials* आइटम पढ़ सकता है। **Always Allow** चुनें। Claude Code द्वारा टोकन बदलने के बाद प्रॉम्प्ट फिर आ सकता है — यह सामान्य है।

आप [स्रोत से बिल्ड](#स्रोत-से-बिल्ड) भी कर सकते हैं।

## यह कैसे काम करता है

AgentBar कभी साइन इन करने को नहीं कहता। यह वे क्रेडेंशियल पढ़ता है जो हर क्लाइंट पहले से आपके Mac पर रखता है और वही एंडपॉइंट कॉल करता है जो क्लाइंट स्वयं करते हैं।

| प्रदाता | क्रेडेंशियल कहाँ से | एंडपॉइंट | क्या दिखाया जाता है |
|---|---|---|---|
| Claude | Keychain आइटम `Claude Code-credentials` (`/usr/bin/security` से पढ़ा गया) | `api.anthropic.com/api/oauth/usage` | 5-घंटे की विंडो, साप्ताहिक विंडो, मॉडल-वार साप्ताहिक सीमाएँ |
| Codex | `~/.codex/auth.json` (या `$CODEX_HOME/auth.json`) | `chatgpt.com/backend-api/wham/usage` | 5-घंटे की विंडो, साप्ताहिक विंडो, प्लान |
| Cursor | `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` (केवल पढ़ने के लिए) | `cursor.com/api/usage-summary`, `…/get-sand-usage-status` | Cursor मॉडल पूल (Auto / Composer / Grok), API मॉडल पूल, ऑन-डिमांड खर्च, साप्ताहिक Grok Bot, इस चक्र में खर्च |

AgentBar टोकन रीफ़्रेश नहीं करता। यदि कोई प्रदाता *सत्र समाप्त* दिखाए, तो उस क्लाइंट को एक बार खोलें — वह टोकन रीफ़्रेश करेगा और AgentBar अगले रीफ़्रेश पर उसे ले लेगा।

## पैनल

- मेनू बार आइकन पर क्लिक करें: सभी प्रदाता तुरंत रीफ़्रेश होते हैं; लोड होते समय पिछले मान दिखते हैं।
- बार 60 % से नीचे हरे, ऊपर पीले और सूचना स्तर पर पहुँचते ही लाल हो जाते हैं।
- हर सीमा बचा हुआ समय और सटीक रीसेट क्षण दिखाती है, जैसे *2घं 15मि में रीसेट · गुरु 24 सित 20:00*।
- सीमा के पास की घंटी का मतलब है कि उसके लिए सूचनाएँ चालू हैं (सेटिंग्स में कॉन्फ़िगर होती हैं)।
- फ़ुटर: आँकड़े · रीफ़्रेश · सेटिंग्स · बंद करें।

## उपयोग आँकड़े

फ़ुटर का चार्ट बटन आँकड़ों की विंडो खोलता है। ऊपर प्रदाता और अवधि बदलें; चार्ट पर होवर करने से दिन का कुल या किसी मॉडल का हिस्सा दिखता है।

| प्रदाता | स्रोत | लागत |
|---|---|---|
| Claude | Claude Code ट्रांसक्रिप्ट (`~/.claude/projects/**/*.jsonl`), एक बार इंडेक्स और प्रति फ़ाइल कैश | वही उपयोग API से कितना खर्च होता: इनपुट/आउटपुट सूची मूल्य पर, कैश लेखन ×1.25 (5-मिनट TTL) / ×2 (1-घंटा TTL), कैश पठन ×0.1 |
| Codex | सत्र लॉग (`~/.codex/sessions/**/*.jsonl`) | OpenAI API सूची मूल्य; कैश किया गया इनपुट ×0.1। सार्वजनिक मूल्य के बिना मॉडल केवल टोकन दिखाते हैं |
| Cursor | Cursor डैशबोर्ड से उपयोग इवेंट, स्थानीय रूप से कैश। पहली बार खोलने पर आप चुनते हैं कि पूरा इतिहास लोड करें या केवल वर्तमान बिलिंग चक्र; बाद के रीफ़्रेश केवल नए इवेंट लाते हैं | जैसा Cursor हर अनुरोध के लिए रिपोर्ट करता है |

**AgentBar के Claude योग Claude Code के `/stats` से अलग क्यों हैं।** Claude Code ट्रांसक्रिप्ट की हर पंक्ति गिनता है, और कई ब्लॉकों (थिंकिंग, टेक्स्ट, टूल कॉल) वाला उत्तर एक ही उपयोग रिकॉर्ड साझा करने वाली कई पंक्तियों में लिखा जाता है — इसलिए वह कई बार गिना जाता है। AgentBar हर उत्तर को अंतिम मानों के साथ एक बार गिनता है — जो API वास्तव में बिल करता है — और तुलना के लिए Claude Code का आँकड़ा साथ में दिखाता है।

700 MB ट्रांसक्रिप्ट को इंडेक्स करने में पहली बार लगभग 10 सेकंड और बाद में एक सेकंड से भी कम लगता है। कैश `~/Library/Application Support/AgentBar/` में रहते हैं।

## सूचनाएँ

- सेटिंग्स → सूचनाएँ में सूचनाएँ चालू करें और डिफ़ॉल्ट स्तर चुनें (50–95 %)।
- किसी भी सीमा को सेटिंग्स → सूचनाएँ में म्यूट किया जा सकता है या अपना स्तर दिया जा सकता है।
- हर सीमा के लिए प्रति रीसेट चक्र एक सूचना मिलती है।
- सीमाएँ हर रीफ़्रेश पर जाँची जाती हैं: स्वतः रीफ़्रेश चालू हो तो शेड्यूल पर, अन्यथा केवल पैनल खोलने पर।

## सेटिंग्स

- **सामान्य** — रीफ़्रेश अंतराल (बंद / 1 / 5 / 15 / 30 / 60 मिनट), दिखाई देने वाले प्रदाता, भाषा, लॉगिन पर लॉन्च, अपडेट।
- **सूचनाएँ** — मुख्य स्विच, डिफ़ॉल्ट स्तर, प्रति-सीमा नियम।

## अपडेट

AgentBar दिन में एक बार और *अपडेट जाँचें* दबाने पर GitHub Releases जाँचता है। नया संस्करण होने पर पैनल में *अपडेट करें* बटन दिखता है। अपडेट डाउनलोड होता है, उसका SHA-256 प्रकाशित चेकसम से मिलाया जाता है, बंडल पहचानकर्ता और संस्करण जाँचे जाते हैं, पुराना ऐप ट्रैश में जाता है और नया लॉन्च होता है। आप [रिलीज़ पेज](https://github.com/funbool/agentbar/releases) से कोई भी रिलीज़ हाथ से भी इंस्टॉल कर सकते हैं।

## स्रोत से बिल्ड

Xcode 15 या नया आवश्यक (Swift 5.9)। कोई तृतीय-पक्ष निर्भरता नहीं।

```bash
git clone https://github.com/funbool/agentbar.git
cd agentbar
swift test                 # यूनिट टेस्ट
./scripts/build.sh         # -> build/AgentBar.app
./scripts/install.sh       # बिल्ड, /Applications में कॉपी और लॉन्च
```

डीबग सहायक (बंडल के अंदर का बाइनरी या `.build/debug/AgentBar` चलाएँ):

```bash
AgentBar --dump            # हर प्रदाता को एक बार पूछकर पार्स की गई सीमाएँ प्रिंट करें
AgentBar --raw             # हर एंडपॉइंट का कच्चा JSON प्रिंट करें
AgentBar --stats           # स्थानीय Claude/Codex लॉग इंडेक्स करके योग प्रिंट करें
AgentBar --cursor-events   # Cursor उपयोग इवेंट लाकर योग प्रिंट करें
AgentBar --update          # पूरा अपडेट चक्र बिना UI के चलाएँ
```

### रिलीज़ करना

```bash
./scripts/release.sh 0.2.0
```

यह `Packaging/Info.plist` में संस्करण बढ़ाता है, `v0.2.0` टैग बनाता है और पुश करता है। GitHub Actions टेस्ट चलाता है, ऐप बिल्ड करता है, `AgentBar.zip` और `AgentBar.zip.sha256` को रिलीज़ के रूप में प्रकाशित करता है, और चल रही कॉपियाँ अगली जाँच पर उसे ले लेती हैं।

## गोपनीयता और सुरक्षा

- **पढ़ता है:** Claude Code Keychain आइटम, `~/.codex/auth.json`, Cursor का `state.vscdb` (केवल पढ़ने के लिए), स्थानीय ट्रांसक्रिप्ट और सत्र लॉग।
- **लिखता है:** `~/Library/Application Support/AgentBar/` में प्राथमिकताएँ और कैश।
- **नेटवर्क:** `api.anthropic.com`, `chatgpt.com`, `cursor.com` (आपका अपना उपयोग डेटा) और `api.github.com` / `github.com` (अपडेट जाँच और डाउनलोड)। और कुछ नहीं।
- रिलीज़ GitHub Actions द्वारा टैग किए गए स्रोत से बिल्ड होती हैं; वर्कफ़्लो `.github/workflows/release.yml` में है।

| लक्षण | क्या करें |
|---|---|

| Cursor कुछ नहीं दिखाता | Cursor को एक बार खोलें ताकि वह सत्र टोकन रीफ़्रेश करे, फिर AgentBar रीफ़्रेश करें। |
| डाउनलोड के बाद ऐप नहीं खुलता | Gatekeeper — देखें [इंस्टॉलेशन](#इंस्टॉलेशन)। |
